# Noise watch apps

Tools for tracking health data from a Noise smartwatch.

| Folder | What it is |
|---|---|
| [`wrist-log/`](wrist-log/) | **Wrist Log**, a one-page tracker for daily sleep, steps, resting heart rate, SpO2, stress and workouts copied from the NoiseFit app. It shows 7-day trends against targets and has a weekly review button. |
| [`gmail-mcp/`](gmail-mcp/) | **gmail-multi**, an MCP server that sends email from more than one Gmail account (work and personal), used to send the weekly health report to a personal inbox. |
